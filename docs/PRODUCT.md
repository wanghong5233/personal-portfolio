# personal-portfolio · 产品需求（唯一事实源）

> 本文件是本仓库（求职站）的需求与方案定稿。对话冲突时以本文件为准。  
> 知识库四层 / 私有站 / 公开笔记站细则见 `../quartz-notes/docs/PRODUCT.md`（路径以本机 monorepo 布局为准）。  
> 版式与页面级细项可参考 `docs/PRD.md`；**与本文冲突时以本文为准**。

## 一句话定义

个人**职业门户**（`wh5233.me`）：简历、作品集、对外可读长文、关于与联系的统一入口。  
服务 HR / 面试官 / 内推；长期可演进为职业主页，不绑死「学生求职站」文案结构。

## 与知识库的关系（定稿）

| | 求职站 | 公开笔记站 | 私有知识库站 |
|---|---|---|---|
| 域名 | `wh5233.me` | `notes.wh5233.me` | `knowledge.wh5233.me` |
| 职责 | 职业门户 + **文章展现壳** | 对外子集的**知识库展现壳** | 自己用完整库 |
| 正文 | **不**在本仓手改第二份 | 同左 | 同左 |

**可编辑真源** = 各持续工作目录（常为独立 Cursor 工作区，不挪仓）。  
本仓文章树、知识库 `content/` 都是 **`mklink /J` 挂载**（或构建时等价读取）；远端 CI 吃各仓 push 快照。

```
原目录（唯一动手改）
   ├─ 联接 → quartz-notes/content/… → notes / knowledge 构建
   └─ 联接 → 本仓文章构建树 → /articles（列表·摘要·长文）
```

### 双展现：都保留

| 形态 | 入口 | 为何留 |
|---|---|---|
| **文章** | `/articles` | 更适合面试扫读（分组、摘要、同站品牌） |
| **知识库** | 导航外链 `notes.wh5233.me` | 树 / 图谱 / 搜索；同一批对外正文的另一壳 |

差别是**展现形式**，不是两套内容。禁止为双入口维护两份可编辑 Markdown。

## 要解决什么

| 问题 | 怎么答 |
|---|---|
| PDF 简历过期 | 固定域名在线简历可更新 |
| 30 秒判断候选人 | 首页状态、方向、代表作、联系方式 |
| 对外长文可读 | 文章形态；正文来自原目录联接 |
| 与笔记站重复维护 | 单原目录；双壳；不 copy 活源 |

## 不做

- 不在本仓长期手改与原目录分叉的第二份文章正文
- 不把知识库私密/加密/本地层内容塞进本站
- 不做博客 CMS / 动态后台 / 炫技动效站
- 不嵌入 Pulse 等作品业务代码（只链证据）

## 导航（当前约定）

可同时保留：首页、作品集、**文章**、**知识库**（外链 notes）、关于、在线简历、联系。  
落地单源后：文章数据源改为联接；导航无需二选一删除。

## 成功标准

1. 面试官可在本站用文章形态读对外长文；需要花园浏览时走知识库外链。
2. 对外正文只在原目录维护；本仓无第二活源。
3. 简历 / 项目 / 联系方式更新闭环短（改内容 → push → 上线）。
4. 新会话读本文件 + 根目录 `AGENTS.md` 即可继续。
