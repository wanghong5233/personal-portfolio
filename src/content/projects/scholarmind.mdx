## 问题背景

研究者在阅读海量论文时缺少可信的检索与摘要工具，单纯的 ChatGPT 难以追溯引用，也难以在多个文档间维持上下文。ScholarMind 的目标是把"论文检索 + 阅读 + 提问"做成可信的工程化应用。

## 我的职责

- 端到端独立设计与开发：前端、后端、数据库、模型链路、部署。
- RAG 召回与引用追溯：chunking、向量检索、reranker、答案中嵌入引用。
- 多文档 Agent 工作流：跨论文对话、笔记、摘要任务。

## 技术架构

- 前端：Next.js + TypeScript + Tailwind。
- 后端：FastAPI + PostgreSQL + pgvector + Redis 队列。
- 模型链路：商业 LLM API + 第三方 reranker + 自维护 chunk 策略。
- 部署：Vercel 前端 + 阿里云 ECS 后端 + Cloudflare Tunnel。

## 核心难点

- 引用追溯：在不牺牲答案质量的前提下，保证回答的每条主张都能映射回原文段落。
- 召回评估：构造可重复的离线评估集，量化 chunking 与 reranker 改动的影响。
- 低成本上线：在 2C2G 主机上稳定承载演示流量。
