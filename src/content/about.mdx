本科从临床医学转到软件工程，硕士做多智能体强化学习，一作发过 IEEE TVT。真正让我把重心移到工程的，是发现受控实验和真实业务之间那段距离没人负责：输入格式不统一，任务会超时，模型会在没人核对的时候把输入悄悄截断。方法本身不缺，缺的是让它稳定复现的那部分。

现在的工作大多在这段距离上：把长剧本变成可核查的结构与原文证据，把分钟级的 LLM 任务改成可恢复的持久化任务，把 Agent 的改写做成能被人审阅的 diff。业余项目按同一个标准推进——Corvia Fit 已进入 Shopify 上架审核，Pulse 至今在替我跑求职流程。

正在找 2027 届大模型应用 / Agent 工程方向的工作。
